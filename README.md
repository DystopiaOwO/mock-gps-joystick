# Mock GPS Joystick

免 Root 的 Android 定位測試工具。它使用系統官方的模擬位置（Mock Location），用畫面上的懸浮搖桿移動座標，也可以在 OpenStreetMap 上點選位置。

App 名稱是 **Mock GPS Joystick**（套件名稱 `tw.dystopia.mockgpsjoystick`）。開啟後標題為「免 Root Mock GPS 搖桿」，並顯示：「僅使用 Android 官方模擬位置功能；不隱藏 Mock 狀態。」

目前公開版本：**v0.2.0**。

## 功能

- 以 Android 官方測試定位提供者寫入 **GPS** 位置，包含速度與方向。高度固定為 0，精度回報為 1 公尺。大約每半秒更新一次。
- 保留系統的模擬位置標記。本 App 沒有 Root、Xposed、Magisk，也不修改其他 App。
- 前景服務執行時會顯示常駐通知「Mock GPS 執行中」，內容為目前座標與速度。
- 懸浮搖桿可選方向。速度有 **1、3、5、10、15、20 km/h**，預設 5 km/h。推過中心附近的小死區後，即以所選速度前進；推得更遠不會更快。
- 搖桿上的「直」可沿最後方向持續前進。
- 主畫面「開啟地圖選點」，以及搖桿上的地圖按鈕「地圖傳送」，都使用隨 App 打包的 Leaflet 地圖，圖磚來自 OpenStreetMap。
- 「已儲存座標」只存在這支手機裡，可命名、儲存、移動與刪除。
- 座標、速度與已存地點都寫在本機，App 不會上傳這些資料。

需要 **Android 8.0（API 26）** 以上。請先自行開啟開發人員選項，並在「選取模擬位置應用程式」選擇本 App。

## 安裝

1. 用手機瀏覽器開啟上方 Releases 頁，下載 `MockGpsJoystick-v0.2.0.apk`。
2. 點下載完成的 APK。若系統擋住，請允許這次安裝：
   - Android 8 以上：到「設定 → 應用程式 → 特殊應用程式存取權 → 安裝未知的應用程式」，對用來開啟 APK 的應用程式（例如 Chrome 或「檔案」）開啟允許。
   - 不同品牌的選單名稱可能略有不同。系統跳出安裝確認時，選擇允許未知來源或繼續安裝。
3. 安裝完成後，從應用程式列表開啟 **Mock GPS Joystick**。

若手機裡已經裝過簽章不同的版本（例如自行建置的測試版），系統會拒絕覆蓋安裝。請先解除安裝舊版，再安裝這個 APK。解除安裝會清掉本機儲存的座標。

## 選取模擬位置應用程式

模擬位置要由你在系統裡指定，本 App 無法替你打開這項設定。

1. 開啟開發人員選項：到「設定 → 關於手機」，連續點「版本號碼」約 7 次，直到出現已成為開發人員的提示。部分品牌把「版本號碼」放在「軟體資訊」裡。
2. 回到設定，打開「系統 → 開發人員選項」。選單位置因品牌而異，也可能直接列在設定最下方。
3. 進入「選取模擬位置應用程式」（有的系統寫成類似的「模擬位置應用程式」）。
4. 選擇 **Mock GPS Joystick**。

也可以在 App 主畫面按「開啟開發人員選項」，再自己找到上述項目。若這支手機沒有對應頁面，App 會提示「此裝置沒有對應的設定頁，請從系統設定手動開啟。」

重新安裝，或是在測試版與正式版之間切換之後，請再確認系統仍選著本 App。

主畫面「權限與設定」的 **Mock Location App** 列會顯示：

| 狀態 | 意思 |
| --- | --- |
| 未選取 | 系統尚未把本 App 設為模擬位置應用程式 |
| 已選取 | 已選本 App，服務還沒在跑 |
| 已驗證 | 模擬位置服務正在執行 |
| 失敗 | 服務沒在跑，且最近錯誤以「Mock Location」開頭。請重新到「選取模擬位置應用程式」選擇本 App |

## 操作說明

開始之前，主畫面上這幾項都要是「是」，而且 Mock Location App 要是「已選取」或「已驗證」：

- 定位權限
- 通知權限（Android 13 以上才會出現「授予通知權限」）
- 懸浮窗權限
- 系統定位

「啟動」只能在目前看得到的主畫面按下。通知不能用來啟動，只能停止或回到 App。

### 主畫面

主畫面由上到下是「權限與設定」、「起始位置」、「執行狀態」。

1. 依需要按下「授予定位權限」、「授予通知權限」、「開啟懸浮窗權限」、「開啟系統定位」，再按「重新整理狀態」。
2. 在「緯度」、「經度」輸入起點。緯度要介於 -90 到 90，經度要介於 -180 到 180。第一次開啟會帶入一組範例座標；之後會記住你上次留下的座標與速度。
3. 或按「開啟地圖選點」，在地圖上選好再回到這裡。
4. 用速度選單選 **1、3、5、10、15、20 km/h**。
5. 按「啟動」。成功後會出現懸浮搖桿與常駐通知。
6. 服務執行中可按「回到起始點」，回到目前記下的起始座標，並停止搖桿移動。服務沒在跑時按它，會提示「服務尚未執行。」
7. 按「停止」結束模擬、搖桿與通知。

「執行狀態」會顯示目前座標、目前速度、方向角、搖桿強度、服務是否執行、懸浮搖桿是否顯示、最近推送時間，以及最近錯誤。

### 懸浮搖桿

搖桿出現在其他 App 上方。圓圈上方內側標有 **N**，往上推是往北。

- **推動圓點**：選擇方向。稍微推離中心就會以目前速度前進；放開後立刻停止。
- **直**：沿最後一次的方向持續前進，速度仍是目前選的速度。再點一次就停止。若還沒推過搖桿就點「直」，會往北前進。開啟時「直」字會帶藍色圓底。
- **速度數字**：顯示目前速度的整數，點一下依序切換 1 → 3 → 5 → 10 → 15 → 20，再回到 1。主畫面的速度選單會跟著更新。
- **地圖圖示**：打開「地圖傳送」。
- **書籤圖示**：打開「已儲存座標」。
- **右上短橫線**：把搖桿縮成小圓點，並停止移動。點小圓點可再展開。
- **上方短橫線一帶**：按住拖曳，可移動整塊搖桿。縮成小圓點時，拖曳也可以移動它。

### 地圖選點

地圖需要網路才能載入 OpenStreetMap 圖磚。畫面上的提示是「點一下或長按選擇位置」。圖磚失敗時會顯示「圖磚載入失敗；請確認網路連線。」

**主畫面的「開啟地圖選點」**

- 標題是「地圖選點」。上方會顯示選到的緯度與經度。載入時先顯示「正在載入地圖…」。
- 「取消」會放棄這次選擇。
- 服務還沒啟動時，「立即傳送到此位置」無法勾選。按「套用」只會把座標填回主畫面，並提示「已套用地圖座標。」
- 服務正在跑時，這個選項預設會勾起，按鈕文字改成「傳送」。按下後目前位置會跳到地圖上的點，並提示「已傳送到地圖座標。」這次傳送不會改寫「回到起始點」用的起始座標。
- 若拿掉勾選，按鈕回到「套用」：只更新起始座標，人留在目前位置。之後按「回到起始點」會去這個新起點。

**搖桿上的「地圖傳送」**

- 面板標題是「地圖傳送」，按鈕為「關閉」與「傳送」。
- 點選或長按地圖後按「傳送」，會立刻跳到該點。
- 面板打開時搖桿會暫時隱藏。若「直」還開著，位置會繼續沿該方向移動。
- 「關閉」不改變位置。

### 已儲存座標

從搖桿書籤打開，標題是「已儲存座標」。

- 「名稱」必填，最多 40 個字。
- 「緯度, 經度」用逗號或空白分開兩個數字。
- 「移動到輸入座標」：直接跳到輸入的座標，不必先儲存。
- 「儲存輸入座標」：用名稱存下輸入框裡的座標。
- 「儲存目前座標」：用名稱存下打開面板當下的位置。
- 「座標清單」列出已存地點。每筆有「移動」與「刪除」。沒有資料時顯示「尚無儲存座標」。
- 用相同名稱再存一次會更新該筆。清單最多保留 100 筆。
- 「移動」會把目前位置跳過去，並放開搖桿。「關閉」或返回鍵可關掉面板。

這些資料只在本機的 App 儲存空間，不會上傳。

### 停止與離開

可以用下列方式停止：

- 主畫面「停止」
- 通知上的「停止」
- 點通知本體只會回到 App，不會因此啟動或停止

從最近任務劃掉本 App，或用返回把主畫面真正關掉，也會停止服務並移除搖桿。旋轉畫面不會停止。

通知頻道名稱是「Mock GPS 執行狀態」。模擬進行時請留著這則常駐通知。

## 常見問題

### 位置沒有變

請依序確認：

1. 「選取模擬位置應用程式」已選擇 Mock GPS Joystick。失敗時，最近錯誤會寫：「Mock Location 啟動失敗。請到「開發人員選項」→「選取模擬位置應用程式」→ 選擇本 App。」
2. 系統定位已開啟，精確定位、通知與懸浮窗都已允許。
3. 是在看得到的主畫面按「啟動」。從背景或其他畫面啟動會提示「只能從目前可見的主畫面啟動。」
4. 有推動搖桿、點了「直」，或用地圖「傳送」。只停在中心時速度是 0。
5. 用會讀取系統 GPS 的地圖或定位狀態工具查看。本 App 只寫入 GPS 測試提供者。會忽略模擬位置、或改用自己的定位來源的 App，畫面可能維持不動。

主畫面裡的座標有在跳，只代表本 App 有把測試位置送出。請再用外部工具看一次。

### 其他 App 顯示這是模擬位置

這是預期行為。本 App 使用官方模擬位置，並保留模擬標記，沒有做任何隱藏或規避偵測。會檢查模擬位置的 App 可以辨認出來，也可能拒絕這筆座標。

### 切到背景後模擬停了

- 從最近任務劃掉本 App 會停止服務。若要繼續，請留著常駐通知「Mock GPS 執行中」，不要把它劃掉。
- 部分手機（例如 Samsung、Xiaomi、OPPO、ASUS）會因電池最佳化結束背景或前景服務。請允許本 App 在背景執行，或關閉它的電池最佳化，並保留通知。
- 通知若被關掉，Android 13 以上請重新「授予通知權限」。沒有通知時，服務可能無法維持在前景。

### 搖桿沒有出現

確認已允許「顯示在其他應用程式上層」，然後停止再啟動一次。請等上一次啟動完成，不要連續快速按「啟動」。若最近錯誤提到懸浮搖桿建立失敗，請回到權限頁重新開啟懸浮窗。

### 地圖是空白的

打開地圖需要網路。失敗時座標列會變成「圖磚載入失敗；請確認網路連線。」連線恢復後重新開啟地圖即可。地圖只下載目前畫面的圖磚，沒有離線地圖。

### APK 無法安裝或無法覆蓋

確認下載的檔名是 `MockGpsJoystick-v0.2.0.apk`，且已允許該來源安裝未知的應用程式。若提示簽章不一致，請先解除安裝手機上的舊版再安裝。

## 開發者建置

一般使用者請用上方的 Releases APK。以下只給要自己編譯的人。

環境：

- JDK 17 以上
- Android SDK Platform 36
- Android SDK Build Tools 35.0.0 以上

專案自帶 Gradle Wrapper。

```bash

./gradlew packageDebugApk
```
