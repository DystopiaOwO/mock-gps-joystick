# 疑難排解

本頁與 [README](../README.md) 的常見問題一致。錯誤文字以 App 與 Gradle 程式為準。

## 位置沒有變

請依序確認：

1. 「選取模擬位置應用程式」已選擇 Mock GPS Joystick。失敗時，最近錯誤會寫：「Mock Location 啟動失敗。請到「開發人員選項」→「選取模擬位置應用程式」→ 選擇本 App。」重新安裝，或在測試版與正式版之間切換之後，請再確認系統仍選著本 App。
2. 系統定位已開啟，精確定位、通知與懸浮窗都已允許。對應提示是「請先開啟手機定位服務。」「請先授予精確定位權限。」「請先授予通知權限。」「請先開啟「顯示在其他應用程式上層」權限。」
3. 「啟動」只在主畫面位於前景，而且服務還沒在跑、也不是正在啟動時可以按。主畫面不在前景時，這個按鈕是停用的。若啟動仍被拒絕，最近錯誤是「只能從目前可見的主畫面啟動。」
4. 有推動搖桿、點了「直」，或用地圖「傳送」。只停在中心時速度是 0。稍微推離中心就會以目前選的速度前進。
5. 用會讀取系統 GPS 的地圖或定位狀態工具查看，或執行 `adb shell dumpsys location`。本 App 只寫入 GPS 測試提供者。會忽略模擬位置、或改用自己的定位來源的 App，畫面可能維持不動。

主畫面裡的座標有在跳，只代表本 App 有把測試位置送出。請再用外部工具看一次。

## 其他 App 顯示這是模擬位置

這是預期行為。本 App 使用官方模擬位置，並保留模擬標記，沒有做任何隱藏或規避偵測。會檢查模擬位置的 App 可以辨認出來，也可能拒絕這筆座標。

## 切到背景後模擬停了

- 從最近任務劃掉本 App，或用返回把主畫面真正關掉，會停止服務並移除搖桿。若要繼續，請留著常駐通知「Mock GPS 執行中」，不要把它劃掉。旋轉畫面不會停止。
- 點通知本體只會回到 App，不會因此啟動或停止。通知上的「停止」才會結束模擬。
- 部分手機（例如 Samsung、Xiaomi、OPPO、ASUS）會因電池最佳化結束背景或前景服務。請允許本 App 在背景執行，或關閉它的電池最佳化，並保留通知。
- 通知若被關掉，Android 13 以上請重新「授予通知權限」。前景服務若無法建立，最近錯誤會以「Foreground Service 啟動失敗：」開頭。

## 搖桿沒有出現

確認已允許「顯示在其他應用程式上層」，然後停止再啟動一次。請等上一次啟動完成，不要連續快速按「啟動」。若最近錯誤是「懸浮搖桿建立失敗，請確認懸浮窗權限是否已開啟。」或提到懸浮搖桿建立失敗，請回到主畫面的「權限與設定」，再按一次「開啟懸浮窗權限」。

## 地圖是空白的

打開地圖需要網路。失敗時座標列會變成「圖磚載入失敗；請確認網路連線。」連線恢復後重新開啟地圖即可。地圖只下載目前畫面的圖磚，沒有離線地圖。

Leaflet 程式與樣式已包在 APK 裡，不從 CDN 載入。

## 回到起始點或書籤移動後，人還在走

「回到起始點」、清單上的「移動」和「移動到輸入座標」會把搖桿強度與實際速度清成 0，但不會重設搖桿上「直」的藍底和圓點位置。所以「直」看起來可能還開著，移動則已經停了。新位置要等下一個約 500ms 的更新週期，才寫入 GPS 測試提供者。

搖桿上的「地圖傳送」按「傳送」會立刻跳到該點。主畫面地圖在服務執行中按「傳送」，則等到下一個更新週期。

## APK 無法安裝或無法覆蓋

確認下載的檔名是 `MockGpsJoystick-v0.2.0.apk`，且已允許該來源安裝未知的應用程式。

Debug 與 Release 簽章不同，不能互相覆蓋。若提示簽章不一致，請先解除安裝手機上的舊版再安裝。解除安裝會清掉本機儲存的座標。Release 更新必須使用首次發布時相同的 JKS。

## Release 缺少簽名檔

本機請依 [APK 建置](build-apk.md) 執行 `tools/generate-release-keystore.ps1`。請勿把 `.jks`、`.keystore`、`keystore.properties` 或密碼加入 Git。

簽名檔不存在時，Release 會停止並顯示：

```text
缺少 release keystore。本機請依 docs/build-apk.md 建立 keystore.properties；CI 請設定 MOCKGPS_KEYSTORE_FILE、MOCKGPS_STORE_PASSWORD、MOCKGPS_KEY_ALIAS 與 MOCKGPS_KEY_PASSWORD。
```

這不影響 `assembleDebug` 或 `packageDebugApk`。
