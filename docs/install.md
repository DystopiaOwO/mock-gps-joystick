# 安裝與設定

1. 使用 ADB 或允許檔案管理器安裝未知來源 APK。
2. 開啟 App，授予精確定位權限。
3. Android 13 以上授予通知權限。
4. 按「開啟懸浮窗權限」，允許顯示在其他應用程式上層。
5. 確認系統定位已開啟。
6. 開啟「設定 → 系統 → 開發人員選項 → 選取模擬位置應用程式」。
7. 選擇 Mock GPS Joystick；不同品牌的設定路徑可能不同。
8. 回到 App，輸入起始座標、選擇速度並按「啟動」。

也可以按「開啟地圖選點」，在 OpenStreetMap 點一下或長按位置，再按「套用」回填主畫面。服務執行中時，可選擇立即移動到地圖位置。

START 只能從目前可見的主畫面按下。通知不會啟動服務，只能停止或帶你回到 App。

## 懸浮控制

- 推動圓形搖桿移動；放開立即停止。
- 點上方速度數字，依序切換 1／3／5／10 km/h。
- 點書籤按鈕開啟座標面板，可輸入名稱與 `緯度, 經度`，或直接保存目前座標。
- 點已儲存座標會立即跳轉；同名保存會更新原座標。
- 點右上短線縮小，點縮小後的圓點重新展開。
- 拖曳上方透明區域可移動整個搖桿。

## 外部讀值驗收

啟動後開啟第三方 GPS status／maps 類 App，或執行：

```powershell
adb shell dumpsys location
```

推動搖桿並確認外部工具讀到的座標同步變化。只有 App 內狀態改變不算 Mock Location 驗收成功。
