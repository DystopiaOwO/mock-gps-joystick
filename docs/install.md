# 安裝與設定

本頁與 [README](../README.md) 的安裝、權限與操作說明一致。按鈕名稱、停用條件與錯誤文字以 App 程式為準。

## 安裝 APK

1. 從 GitHub Releases 下載 `MockGpsJoystick-v0.2.0.apk`。下載頁：<https://github.com/DystopiaOwO/mock-gps-joystick/releases>
2. 本 App 需要 Android 8.0（API 26）以上。點下載完成的 APK 時，系統是針對「這個來源」詢問能不能安裝。若被擋住，到「設定 → 應用程式 → 特殊應用程式存取權 → 安裝未知的應用程式」，對用來開啟 APK 的應用程式（例如 Chrome 或「檔案」）開啟允許。不同品牌的選單名稱可能略有不同。
3. 安裝完成後，從應用程式列表開啟 **Mock GPS Joystick**。

若手機裡已經裝過簽章不同的版本（例如自行建置的測試版），系統會拒絕覆蓋安裝。請先解除安裝舊版，再安裝這個 APK。解除安裝會清掉本機儲存的座標。

自行編譯請看 [APK 建置與簽名](build-apk.md)。

## 選取模擬位置應用程式

模擬位置要由你在系統裡指定，本 App 無法替你打開這項設定。

1. 開啟開發人員選項：到「設定 → 關於手機」，連續點「版本號碼」約 7 次。部分品牌把「版本號碼」放在「軟體資訊」裡。
2. 打開「系統 → 開發人員選項」。選單位置因品牌而異，也可能直接列在設定最下方。
3. 進入「選取模擬位置應用程式」（有的系統寫成類似的「模擬位置應用程式」）。
4. 選擇 **Mock GPS Joystick**。

也可以在主畫面按「開啟開發人員選項」，再自己找到上述項目。若這支手機沒有對應頁面，App 會提示「此裝置沒有對應的設定頁，請從系統設定手動開啟。」

重新安裝，或是在測試版與正式版之間切換之後，請再確認系統仍選著本 App。

主畫面「權限與設定」的 **Mock Location App** 列：

| 狀態 | 意思 |
| --- | --- |
| 未選取 | 系統尚未把本 App 設為模擬位置應用程式 |
| 已選取 | 已選本 App，服務還沒在跑 |
| 已驗證 | 模擬位置服務正在執行 |
| 失敗 | 服務沒在跑，且最近錯誤以「Mock Location」開頭。請重新到「選取模擬位置應用程式」選擇本 App |

## 啟動前

開始之前，主畫面上這幾項都要是「是」，而且 Mock Location App 要是「已選取」或「已驗證」：

- 定位權限（「授予定位權限」）。程式會檢查精確定位。
- 通知權限。Android 13 以上才會出現「授予通知權限」；Android 12 以下沒有這個按鈕。
- 懸浮窗權限（「開啟懸浮窗權限」）。
- 系統定位（「開啟系統定位」）。沒開時會提示「請先開啟手機定位服務。」

「啟動」只在主畫面位於前景，而且服務還沒在跑、也不是正在啟動時可以按。主畫面不在前景時，這個按鈕是停用的。通知不能用來啟動，只能停止或回到 App。

1. 依需要按下權限按鈕，再按「重新整理狀態」。
2. 在「緯度」、「經度」輸入起點，或按「開啟地圖選點」。緯度要介於 -90 到 90，經度要介於 -180 到 180。第一次開啟會帶入一組範例座標，速度是 5 km/h；之後會記住你上次留下的座標與速度。
3. 用速度選單選 **1、3、5、10、15、20 km/h**。
4. 按「啟動」。成功後會出現懸浮搖桿與常駐通知「Mock GPS 執行中」。

「回到起始點」只在服務執行中可以按。按下後，目前座標回到記下的起始位置，搖桿強度與實際速度清成 0；搖桿上「直」的藍底和圓點位置不會因此重設。新位置要等下一個約 500ms 的更新週期，才寫入 GPS 測試提供者。服務沒在跑時這個按鈕停用。

「執行狀態」會顯示目前座標、目前速度、方向角、搖桿強度、服務是否執行、懸浮搖桿是否顯示、最近推送時間，以及最近錯誤。

## 懸浮搖桿

搖桿出現在其他 App 上方。圓圈上方內側標有 **N**，往上推是往北。

- **推動圓點**：選擇方向。稍微推離中心就會以目前速度前進。沒有開「直」時，放開後立刻停止；「直」開著時，放開後仍沿最後方向繼續前進。
- **直**：沿最後一次的方向持續前進，速度仍是目前選的速度。再點一次就停止。若還沒推過搖桿就點「直」，會往北前進。開啟時「直」字會帶藍色圓底。
- **速度數字**：顯示目前速度的整數，點一下依序切換 1 → 3 → 5 → 10 → 15 → 20，再回到 1。服務執行中，主畫面的速度選單會跟著更新。
- **地圖圖示**：打開地圖面板，標題是「地圖傳送」。
- **書籤圖示**：打開「已儲存座標」。
- **右上短橫線**：把搖桿縮成小圓點，並停止移動。點小圓點可再展開。
- **上方短橫線一帶**：按住拖曳，可移動整塊搖桿。縮成小圓點時，拖曳也可以移動它。

## 地圖選點

地圖需要網路才能載入 OpenStreetMap 圖磚。畫面上的提示是「點一下或長按選擇位置」。圖磚失敗時會顯示「圖磚載入失敗；請確認網路連線。」

**主畫面的「開啟地圖選點」**

- 標題是「地圖選點」。一打開，上方就是目前的緯度與經度。
- 「取消」會放棄這次選擇。
- 服務還沒啟動時，「立即傳送到此位置」無法勾選。按「套用」只會把座標填回主畫面，並提示「已套用地圖座標。」
- 服務正在跑時，這個選項預設會勾起，按鈕文字改成「傳送」。按下後目前位置會跳到地圖上的點，並提示「已傳送到地圖座標。」「回到起始點」用的起始位置不會改，但主畫面的「緯度」「經度」和本機記住的座標會改成地圖上的點，所以欄位上的數字和「回到起始點」可能不一樣。
- 若拿掉勾選，按鈕回到「套用」：只更新起始座標，人留在目前位置。之後按「回到起始點」會去這個新起點。

**搖桿上的「地圖傳送」**

- 面板標題是「地圖傳送」，按鈕為「關閉」與「傳送」。一打開就顯示目前座標。
- 點選或長按地圖後按「傳送」，會立刻跳到該點。
- 面板打開時搖桿會暫時隱藏。若「直」還開著，位置會繼續沿該方向移動。
- 「關閉」不改變位置。

## 已儲存座標

從搖桿書籤打開，標題是「已儲存座標」。

- 「名稱」必填，最多 40 個字。
- 「緯度, 經度」用逗號或空白分開兩個數字。
- 「移動到輸入座標」：跳到輸入的座標，不必先儲存。效果與清單上的「移動」相同。
- 「儲存輸入座標」：用名稱存下輸入框裡的座標。
- 「儲存目前座標」：用名稱存下打開面板當下的位置。
- 「座標清單」列出已存地點。每筆有「移動」與「刪除」。沒有資料時顯示「尚無儲存座標」。
- 用相同名稱再存一次會更新該筆。清單最多保留 100 筆。
- 「移動」和「移動到輸入座標」都會把目前座標改到目標點，把搖桿強度與實際速度清成 0，然後關閉面板。搖桿上「直」的藍底和圓點位置不會重設，所以「直」看起來可能還開著，移動則已經停了。新位置要等下一個約 500ms 的更新週期，才寫入 GPS 測試提供者。
- 「關閉」或返回鍵只關掉面板，不改變位置。

這些資料只在本機的 App 儲存空間，不會上傳。

## 停止與離開

可以用下列方式停止：

- 主畫面「停止」
- 通知上的「停止」
- 點通知本體只會回到 App，不會因此啟動或停止

從最近任務劃掉本 App，或用返回把主畫面真正關掉，也會停止服務並移除搖桿。旋轉畫面不會停止。

通知頻道名稱是「Mock GPS 執行狀態」。模擬進行時請留著這則常駐通知。

## 外部讀值

啟動後開啟會讀取系統 GPS 的地圖或定位狀態工具，或執行：

```powershell
adb shell dumpsys location
```

有推動搖桿、點了「直」，或用地圖「傳送」之後，外部讀值才應該變化。只停在搖桿中心時速度是 0。主畫面裡的座標有在跳，只代表本 App 有把測試位置送出。
